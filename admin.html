Admin password

Your password is stored securely as a Netlify environment variable — never in the browser. To change it:

  1. 1
    Go to Netlify dashboard → your site → Site configuration → Environment variables.
  2. 2
    Find ADMIN_PASSWORD and click Edit.
  3. 3
    Set your new password and save. It takes effect immediately on the next login.
